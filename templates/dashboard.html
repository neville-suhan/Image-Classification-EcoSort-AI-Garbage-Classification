05
⚖️
Dataset Balancing via Class Weights
Extreme class imbalance — Clothes (~5,000 images) vs Brown Glass (~600 images) — was handled using compute_class_weight('balanced') from scikit-learn. This computes per-class weights inversely proportional to their sample count, penalising the model more for errors on minority classes.
Inverse Frequency Imbalance Correction Fairness
⚖️

Why Class-Weight Balancing Matters

Without balancing, a model trained on 5,000 Clothes images alongside 600 Brown Glass images would develop a strong bias — always predicting "Clothes" to minimise overall loss, regardless of actual content. The minority classes would be effectively ignored.

compute_class_weight('balanced') forces the model to treat every class with equal importance — penalising minority class errors proportionally more, resulting in a truly fair multi-class classifier.

n_samples ÷ (n_classes × n_i)

05 — Important Note

Classification Note for Users

⚠️

Organic & Biological — Functionally Equivalent Classes

Our dataset contains two closely related waste categories: Organic and Biological. In the context of this classification system, both categories refer to biodegradable waste — such as food scraps, plant matter, garden waste, and other naturally decomposable materials.

These classes were maintained separately in the dataset to improve model granularity; however, from a disposal and recycling standpoint, they are interchangeable. Both types of waste should be directed to compost bins, food waste collection, or biogas processing facilities.

📌 Therefore, if the model predicts either "Organic" or "Biological" for an uploaded image, the recommended action and disposal method are identical. Users need not distinguish between the two — treat both predictions as one unified biodegradable waste category.
