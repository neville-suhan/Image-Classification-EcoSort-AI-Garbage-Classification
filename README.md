Garbage Classification using AI ♻️🧠

An AI-powered Garbage Classification Web Application built using Deep Learning and Computer Vision techniques to classify waste images into multiple categories for better waste management and recycling awareness.

The system uses pretrained CNN models such as MobileNetV2, EfficientNet, ResNet, and DenseNet for image classification and provides disposal tips and recycling ideas for each waste category.

📌 Project Overview

This project focuses on smart garbage classification using Image Classification techniques.
Users can upload an image of waste material, and the system predicts the garbage category using a trained deep learning model.

The application also provides:

♻️ Disposal methods
🎨 Recycling / craft ideas
📊 Confidence score
🌍 Eco-friendly awareness

The project was developed as part of an AI & Data Science project implementation using Deep Learning and Flask.

📊 Model Comparison
Model	Validation Accuracy	Speed
MobileNetV2	86.8%	⚡ Fastest
EfficientNet	85.2%	⚡ Moderate-Fast
DenseNet	83.1%	🐢 Slow
ResNet50	82.3%	🚶 Moderate
VGG16	78.6%	🐢 Very Slow

✅ MobileNetV2 was selected as the final production model due to its best balance between speed and accuracy.
